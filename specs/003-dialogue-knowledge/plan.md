# 实施方案

1. 在阶段 2 的统一命令层前收敛中英文命令识别。只在确认后执行修改。流式对话和工具校验复用该识别。
2. 开课前以现有草稿收集明确提供的需求，先问一个未确认字段。模型仅提供候选课程编号；持久化进度仍由会话命令控制。
3. 在知识策略中共享可用性判定，教学单独要求有效来源和许可。课程计划固定步骤内容及来源版本；语言切换使用满足同一准入状态的对应版本。
4. 保留后台的人工审核、冲突检测和索引重建。用基础课和检索样例固定可复查证据，审核字段由实际审核者填写。
5. 流式模型公开只读工具和受限候选工具；此前直接进度工具不再提供给模型。兼容调用如保留，由服务端验证显式意图，不另建状态机。

## 回退

无 SQL 表结构变化。计划与知识使用向后读取兼容的可选字段。部署回退前保留 SQLite 备份；旧版读取新字段需先对备份运行字段级回退或恢复部署前的库。开发草稿和试用门控可单独核对，回退不改变审核事实。

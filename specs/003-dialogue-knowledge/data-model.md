# 课程数据、迁移与回退

- PlanNeeds 新增可选避讳和明确填写字段。草稿修改基于最新计划；活动计划的偏好输入不触发替换。
- MakeupStep 可携带步骤版本和来源快照。候选模型调用只提供步骤编号。管理员更新不篡改已有计划的正文。
- SourceRecord 增加使用许可与依据。两条团队原创来源更新版本，未改变审核标记。历史来源缺许可仍可作为来源数据查看，需补齐许可才能编入课程。
- 新代码读取旧计划时为可选字段补默认值。旧代码对未知字段严格校验。回退先停止应用，再从启用新版本前的独立 SQLite 备份恢复；保留新版数据库副本供审计，禁止覆盖唯一一份记录。知识文件按 Git 回退。无需执行 SQL 表结构迁移。

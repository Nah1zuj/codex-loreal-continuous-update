# 自然日常基础课与审核

课程按准备、轻薄底妆、腮红、唇妆和收尾排序。中文版使用 `coaching_prep_zh`、`coaching_foundation_zh`、`coaching_blush_zh`、`coaching_lips_zh`、`coaching_finish_zh`，英文使用对应的 `_en` 版本。每步在知识文件中分别定义用具、准备、操作、触觉定位、常见失误和本人确认标准。用户明确排除可选妆容环节时按该范围重新验证候选。其他风格仅在各自的必要步骤和语言均可用时进入相应模式。

1. 核对来源的内容版本、可复查文件或链接、使用许可与依据。团队原创来源为 `trace_original_phase4`，版本 2。
2. 使用知识后台读取课程记录。实际专业审核者检查动作、安全限制、辅助定位、工具可替代性、中英一致性与本人确认标准，在记录页填写真实审核者并明确保存审核结果。
3. 审核记录含状态、审核人、时间和版本。修改需再确认并更新版本。应用重建索引后检查旧版本停用和试用模式过滤。
4. 用 [检索样例](../../AccessibleBeautyAgent/tests/fixtures/lesson_retrieval.json) 比对命中条目、任务线索、来源、版本和准入。样例只证明对应过滤场景；无专业内容审核结论。

当前中英记录均为原创工程草稿。用测试库演示审核流程的合成署名只存在于临时库。

# 语音生命周期实施方案

- WebSocket 工作者负责音频缓冲与识别边界。按钮与关键词进入同一个识别服务，丢弃只返回原因，不返回文本。事件携带 epoch，旧连接和旧 epoch 的事件无法触发新请求。
- 本机语音适配器负责权限、连接期限、音频设备释放和协议转换。通话控制器统一管理阶段、语音提交和播报。页面保留控件与状态显示。
- 以现有合成音频、模拟控制器和 Chrome 隔离环境建立第一批软件证据。设备检查包括真实背景音和回声，记录设备、系统及输入来源。
- 当前批次不更改 SQLite。兼容现有 worker 消息，丢弃原因采用新增可选字段，旧客户端可以继续读取既有的 discarded 标志。

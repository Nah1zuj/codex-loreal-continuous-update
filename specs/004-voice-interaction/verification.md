# 语音生命周期验证

**环境** macOS arm64、Chrome 156.0.8078.81、Python 3.12、Node 26，独立 TRACE 服务。浏览器使用合成设备，样本 WAV 来源见开发检出的 `voice/fixtures/00_合成音频说明.txt`。

| 要求 | 软件结果 | 证据 |
|---|---|---|
| FR-401 按钮与起止词 | PASS | `voice/test_bounded.py` 覆盖关键词、按钮、交叉结束与单次提交。真实 WebSocket 重放 `voice/verify_stream.py` 新增按钮重复结束及撤销旧 epoch 两例。 |
| FR-402 阶段与文字 | PASS（软件） | 控制器区分录音、转写、请求及播报。服务端发出转写阶段，界面提供状态和弃录控件；组件回归覆盖文字继续使用。 |
| FR-403 生命周期 | PASS（软件） | 浏览器离开语音工作区释放麦克风，刷新后连接数从 1 回到 0，站点记住权限也无新请求。模拟权限延迟返回时释放轨道，关闭取消连接计时器。 |
| FR-404 120 秒 | PASS（确定性） | 音频样本长度超限直接清除且不调用 ASR；当前 epoch 报明确原因，过期事件丢弃。 |
| FR-405 失败与重复 | PASS（软件） | 本机识别、通话控制和合成 WebSocket 用例覆盖拒绝、取消、过期结果、丢弃及播报失败。普通语音不会在处理或播报中启动新请求。 |
| FR-406 双平台实体 | NOT RUN | 麦克风、耳机、扬声器、背景声、回声与断连应在 Mac 和 Windows 实体检查，自动化和合成设备不能作为该项证据。 |

同一浏览器实际服务中，`verify_stream.py` 共 9 个用例通过。Python `-m unittest discover -s voice -p test_bounded.py` 9 项通过。浏览器复现及本地配置说明见 [会话验证](../002-session-control/verification.md)。

验收修订版新增中文关键词编码回归，语音单元测试增至 10 项。原实现在模拟 CP1252 时写入失败，修复后两份关键词文件均为 UTF-8。在本机实际模型上另用 `LC_ALL=C PYTHONUTF8=0` 和含中文空格的独立目录启动模型，验证默认编码为 US-ASCII 时仍可加载两套关键词和转写模型。实体麦克风、扬声器、耳机和 Windows 启动另行验收。

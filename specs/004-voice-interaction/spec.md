# 004 语音交互与生命周期

**依据** [整改计划](../../docs/quality/roadmap.md) 阶段 4。软件实施与实体评审分别记录。

- **FR-401** 按钮与起止词走同一条本机识别、对话请求和播报路径。一段成功的录音最多提交一次。
- **FR-402** 可区分等待、录音、转写、请求、播报、暂停、已关闭和不可用。读屏可获得状态，文字输入保留。
- **FR-403** 丢弃本段、离开语音工作区、关闭麦克风以及设备丢失后，未提交录音不得触发对话。释放受此会话管理的麦克风、音频处理及连接。语音与映照页面是同一个工作区，可以显式切换而保留通话。
- **FR-404** 单段上限 120 秒。超限丢弃并提示时限，空白和无法识别边界的输入提示重录。
- **FR-405** 请求或播报期间拒绝普通语音；暂停和明确的按钮打断仍可用。断连、设备丢失、识别与播报异常可回到可操作状态。
- **FR-406** Mac 与 Windows 使用实际麦克风、耳机与扬声器核验暂停、断连、背景音、回声和资源释放。合成测试结果与设备验收分列。

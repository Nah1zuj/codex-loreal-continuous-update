# 阶段 7 · 确认式记忆、日志与数据管理

- FR-701 课程结束生成候选，用户可查看、朗读、改标题和私人备注、保存或拒绝。步骤事实来自权威计划，不能在候选中改写。查看、朗读和预览不保存个人记忆。
- FR-702 保存绑定候选与所审阅内容版本，完全相同的重复保存返回同一记录。变更后重新预览。拒绝和删除阻止旧确认重放。
- FR-703 摘要、独立日志、聊天原文和偏好使用各自确认。摘要不自动派生偏好或进入模型输入。日志可独立写、看、编辑和删除。
- FR-704 旧自动记录显式显示来源，可以重新审阅确认或删除。复用仅由用户选定已确认记录后发起；删除立即清除复用指针和派生数据。
- FR-705 完成进度和已确认摘要默认 30 天；日志、已确认偏好保留至用户删除。所有操作以已验证的浏览器所有者作用域执行，管理员不绕过。

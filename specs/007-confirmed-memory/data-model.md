# 私人数据生命周期

SQLite 迁移 4–6 为加法迁移。旧摘要、日志和偏好保留原表，不推断旧摘要的用户确认状态。

| 数据 | 保留与删除 |
|---|---|
| 教学进度和命令事件 | 进度表 30 天，启动或读取拾光时清理。删除进度触发清除命令事件及其回执。 |
| 摘要候选 | 按所有者、课程版本及内容即时构建。预览和朗读无保存。确认摘要保留 30 天。旧自动摘要按原 30 天规则保留来源。 |
| 拒绝或删除摘要 | 无正文墓碑保留 30 天，阻止已拒绝或已删除候选回放。删除已重新确认的旧摘要同步清除对应旧记录。 |
| 私人日志 | 原文与日志分开同意。日志与偏好留到用户删除；可选原文最多 30 天，删除日志同步删除关联原文。 |
| 偏好 | 提交用进程内签名验证候选，成功回执独立持久化。删除后失效回执、重算档案，清理已知旧日志派生快照与后续对话上下文。 |
| 版本与回执 | 同一确认重复提交返回原记录。编辑后旧版本不再接受。日志旧调用无标识时按所属用户及提交内容计算稳定请求标识；新界面用显式标识。删除后仅留回执占位或墓碑以拒绝旧请求。 |

回退需要停止服务并保留当前库副本，再以迁移前备份恢复与历史代码配套的数据。避免使用曾自动写摘要的旧版进行真实部署。本次测试用隔离库和合成历史记录，没有迁移日常 SQLite。

# 实施方案

- 使用 SQLite 加法迁移，保留旧摘要、日志和偏好表。确认摘要单独保存版本、来源、时间和可选复用标记。
- 候选根据所有者、计划版本与事实即时计算。编辑预览重新计算内容版本。确认在事务中写入，重复提交返回同一记录。拒绝、删除保留不含文本的 30 天墓碑。
- 复用只传递确认的风格枚举，备注和摘要名称不会进入未来远程模型上下文。新教学独立记录，复用删除不影响正在进行的课程。
- 独立日志保留现有入口，补充按版本编辑及稳定请求标识。旧直接保存调用继续要求显式确认。
- 日常库由启动迁移，验证全部使用隔离数据库。回退前备份 SQLite，旧版无新增摘要功能；不得把旧自动保存版本用于生产回退。

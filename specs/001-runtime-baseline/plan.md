# 运行基线实施方案

## 概要与环境

沿用 Python 3.12、FastAPI、SQLite、React、Vite 与 Sherpa。本阶段不迁移业务数据结构。Node 26.10.0 为复现基线。共享安装由 Python 执行，平台脚本仅选择解释器和转发参数。

## 设计

- 应用根目录提供唯一端口和版本描述。启动器管理三进程，使用系统文件锁防止同一工作目录重复启动，Vite 严格绑定端口。自测显式传入隔离端口和工作目录。
- Vite 代理复用同一配置。后端与语音依据前端端口允许本机来源。已有直接开发调用保留适配。
- 运行环境或配置不匹配时返回可操作信息。安装锁包含绝对路径、平台和依赖输入摘要，移动后重建环境。
- 检查模型使用固定 SHA-256。下载验证后替换文件，旧模型与配置在原地保留。服务缺少语音模型时报告不可用，文字继续工作。
- 测试从项目内 `work` 获取独立临时目录，禁用日常 dotenv 与远程服务。动态分配端口用于真实进程测试。
- 旧安装脚本退出重复依赖解析；旧 Vite 包装配置迁移至同一入口；旧文档与旧脚本只在历史目录留存。

## 章程核对

FR-101 至 FR-106 覆盖最小改造、数据隔离和分层证据。无权限或课程状态变更。阶段 2 在核对回归后细化规格。

## 迁移与回退

安装环境可重建。原 SQLite、`.env` 和模型文件不迁移。保留原标签，可在独立目录回退源代码。已有测试和 API 字段保留，健康检查增量返回字段。

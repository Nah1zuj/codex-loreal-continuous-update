# TRACE 运行与测试基线

**编号** 001 · **阶段** 1 · **依据** [整改计划](../../docs/quality/roadmap.md)

## 用户场景与验收

### US-01 安装并运行（P1）

队友在 Mac 或 Windows 上进入首次安装入口，打开应用，关闭时只停止本次启动的服务。目录带中文、空格或移动后，仍可启动。知识库与 SQLite 可用，语音模型缺失时仍可使用文字。

### US-02 判断服务可用性（P1）

队友可以区分端口占用、依赖缺失、模型未加载、SQLite 不可用与远程服务待验证。端口被其他程序占用时不关闭对方，重复启动不新增进程。没有麦克风授权时可以查看诊断。

### US-03 运行回归（P1）

队友不依赖个人配置、用户数据库与日常端口就能运行后端、前端、构建与知识库检查。原本失败的断言保留。结果标出模拟、设备与平台范围。

## 功能要求

- **FR-101** 固定 Python 3.12 系列、Node 验证版本、Python 与 npm 依赖。安装及启动仅保留共享逻辑和平台入口。
- **FR-102** 模型有版本、来源和校验，缺失时提供明确安装命令。视觉和语音的依赖、文件、加载、实际设备结果分别记录。
- **FR-103** 启动器严格使用本机回环及指定端口。只关闭本次启动的子进程。配置和安装缓存可随项目移动而重新生成。
- **FR-104** 后端测试默认使用隔离 SQLite 和 mock 配置；运行冒烟使用独立端口及数据库。
- **FR-105** 健康检查区分服务、依赖、配置、真实功能验证。诊断不输出凭证。
- **FR-106** 启动及回归覆盖普通、中文空格路径、目录移动、占用与重复启动。干净安装、Mac 与 Windows 各有可复查结果。

## 验收标准

- SC-01 安装说明可从干净环境执行，四项自动化检查记录结果。
- SC-02 健康检查可通过页面代理同时确认 UI、API 和本地语音可达；缺少语音时文字和健康检查可用。
- SC-03 重复启动只报告正在运行的本目录实例或冲突；第三方监听保持存活。退出后所启动端口释放。
- SC-04 核对测试前后日常 SQLite 不变。真实设备与远程服务另列。

## 澄清记录

- 按 Python 3.12.x 支持兼容补丁，实际证据记录具体补丁号。Node 固定本地验证版本。
- 软件测试允许替换端口，并保留用户打开旧书签所使用的默认页面端口 5180。
- Windows 验证独立于 Mac。交叉下载或语法检查仅作为依赖与实现证据。
- 缺少模型时文字正常运行；模型下载仅在明确执行安装资产命令时发生。

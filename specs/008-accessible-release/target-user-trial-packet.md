# 目标用户关键任务试用准备包

关联任务：[#12 开展目标用户关键任务试用并判定真实试用资格](https://github.com/Nah1zuj/codex-loreal-continuous-update/issues/12)

本页是观察人员使用的准备材料，不是已完成的目标用户证据。只有 Issue #8 的真实专业课程审核和 Issue #11 的工程候选判定都通过，并固定试用包及 Git commit 后，才可开始真实试用。模板、团队演练、自动化测试和合成记录均不得写成盲人或低视力参与者试用。

## 开始门槛

观察人员开始前逐项确认；任一项不满足即记录 `BLOCKED`，不邀请参与者操作未达到门槛的版本。

- Issue #8 已由实际专业审核者确认通过，课程版本与结论可复查。
- Issue #11 已判定为工程候选；固定 commit、交付包 SHA-256、安装和回退结果可复查。
- 本轮使用的系统、浏览器、读屏或放大工具与版本已记录。
- 参与者已经获得易理解的试用说明，知道这是试验版本、可以拒绝任何任务、随时暂停或退出，退出不产生不利后果。
- 已说明数据边界：仓库只保留参与者编号和匿名观察；姓名、联系方式、招募沟通、照片、录音、原始屏幕录像及其他可识别资料不进入仓库。
- 若现场另行采集媒体，须有与本轮观察分开的明确同意、保存期限和删除方式；本准备包不授权任何媒体采集。

## 观察规则

观察人员只读出任务目标，不解释界面位置或正确操作。参与者可使用自己熟悉的读屏、放大、键盘或其他辅助工具。每个任务只记录以下一种结果：

| 结果 | 定义 |
| --- | --- |
| `independent` | 未获得任务操作提示，参与者自行完成并能说明关键状态。重复任务目标不算操作提示。 |
| `prompted` | 在获得界面位置、控件名称、操作顺序或排错提示后完成；必须记录提示内容与次数。 |
| `not_completed` | 未在参与者愿意继续的范围内完成，或关键状态理解错误；记录卡点，不催促继续。 |
| `withdrawn` | 参与者选择停止该任务或整轮试用；不要求说明理由，不把退出写成失败。 |

如果出现隐私风险、无法退出的流程、媒体未按预期停止、严重不适、数据意外保存或参与者要求停止，应立即结束相关操作，记录匿名事件并按严重程度建立 Issue。观察人员不得为了完成率引导参与者继续。

## 三项关键任务

任务顺序可以按参与者需要调整，但不得省略后再宣称通过。

1. **开始、暂停并恢复一节课**：参与者能辨认当前步骤，主动暂停并恢复，且知道如何结束。
2. **拒绝媒体权限后继续文字**：参与者拒绝麦克风或相机，能说明发生了什么，并自行回到文字操作；不要求开启真实媒体。
3. **查看小结并自主保存或放弃**：参与者能说明待保存内容属于哪次操作，并按自己的选择保存或放弃；不得诱导保存。

每项记录：结果、提示次数、逐步匿名观察、参与者对状态或失败提示的理解、产生的 GitHub Issue 编号。不要把推测写成参与者原话；需要保留短句时先确认不会造成身份识别。

## 记录文件

将 [合成示例](target-user-trial-record.synthetic.json) 复制到仓库外的受控位置填写。真实观察完成并去除个人信息后，团队再决定是否把匿名派生记录纳入仓库。字段约束由下列命令检查：

```bash
python AccessibleBeautyAgent/scripts/verify_target_user_trial_record.py path/to/record.json
```

校验器会区分：

- `ELIGIBLE`：真实目标用户记录、两项前置通过、三项均独立完成、无开放关键问题且声明结论一致。
- `NOT_ELIGIBLE`：真实记录有效，但任务未全部独立完成、存在开放关键问题或结论不满足门槛。
- `BLOCKED`：合成记录、前置未通过或声明仍待判定；不得用作真实试用通过证据。
- `INVALID`：字段缺失、值不合法、出现明显联系方式或结论与证据矛盾。

机器校验只检查格式和显式门槛，不能证明参与者身份、自愿条件、观察真实性或问题是否已妥善解决。

## 资格判定

真实试用版的判定至少同时满足：

- 实际参与条件、样本数和每个匿名记录可复查；样本数按实际报告，不预设或虚构。
- 每位纳入通过结论的参与者三项关键任务均为 `independent`，并能理解相关状态或失败提示。
- 所有影响关键任务、退出、隐私或数据控制的问题均有 Issue、处置和同版本复验记录。
- 结论明确绑定试用 commit、包 SHA-256、课程审核版本和辅助工具环境。

不满足时保持内部验证版或工程候选分类，并如实记录 `NOT_ELIGIBLE` 或 `BLOCKED`；不得用平均完成率掩盖关键任务失败，也不得把提示后完成改写为独立完成。

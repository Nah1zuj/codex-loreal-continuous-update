# 008 无障碍与交付验收

依据 [整改计划](../../docs/quality/roadmap.md) 阶段 8。

- **FR-801** 入口、教学、拒绝授权、继续使用及记录均有可操作的键盘路径。焦点顺序清晰，状态在中英文下可感知。正常与加大字号、缩放及减少动态效果均保留关键内容和控制。
- **FR-802** 避免默认应用播报与读屏重复。用户可主动开启声音或使用文字。同一通话状态只有一个自动播报区域。
- **FR-803** 以独立配置验证移动目录、无模型、断网、进程中断与重启、长会话和媒体清理。结果能按阶段复查。
- **FR-804** 从固定 Git 版本生成交付包及清单。排除凭证、个人数据库和媒体；界面正式资产与公开资源依据来源保留。统一运行、演示、回退及已知限制说明。
- **FR-805** Mac Chrome＋VoiceOver 与 Windows Chrome＋NVDA 均完成实体复核。无未解决 P0 和核心 P1，且各阶段技术检查满足后标为工程候选。只有专业课程审核和目标用户验收通过后可标为真实试用版。

# 无障碍与交付验收

版本 `TRACE-20261107-internal`。本轮结果以 Git 提交、运行清单和各阶段验证记录为准。当前分类为内部验证，发布资格分别按下表检查。

| 要求 | 当前证据 | 未关闭项 |
|---|---|---|
| FR-801 键盘、语言、字号及减少动画 | macOS Chrome 156 无头实测。首个 Tab 到跳转链接，落点为主要内容；中英切换保留控件焦点，英文可访问树包含正确的文本框名称。启用减少动画及大字号后，640px 下保持文本入口可见且无整页横向滚动。 | 双平台实际 200% 浏览器缩放和实体读屏。 |
| FR-802 播报与读屏 | 软件检查覆盖默认静默、主动朗读欢迎和单个通话状态 live region。文字会话在应用正在朗读时抑制重复的内容播报。 | VoiceOver 和 NVDA 的实际播报顺序及打断。 |
| FR-803 运行与恢复 | [运行基线](../001-runtime-baseline/verification.md)、[会话浏览器](../002-session-control/verification.md)、[长会话及媒体](recovery-and-media.md)。隔离 Chrome 使用合成设备，真实本机服务核对断流、重启、撤权和端口回收。 | Windows 实机环境，实际音频和相机样本。 |
| FR-804 交付包 | 发布工具从指定提交取源码，审核路径、版本与清单，移除非公开媒体及旧启动器。 [运行、演示与回退](../../docs/quality/release-runbook.md) | 新包的复核结论随下方构建记录更新。 |
| FR-805 工程候选与真实试用 | 内部软件结果分阶段记录。 | Mac Chrome＋VoiceOver、Windows Chrome＋NVDA、实际设备、外部供应商凭证、专业课程审核和目标用户验收。 |

Chromium 无头配置、注入网络故障与浏览器合成媒体用于软件验证。实体音视频、真实 OCR 与模型提供商，以及人的实际读屏操作分别验收。上线和真实试用保持关闭。

# 006 · 今日造型、标签读取与产品比较

- FR-601 六个领域可单独选择、跳过、修改和确认。局部变更仅更新目标领域，版本不符时返回当前版本供刷新。
- FR-602 方案分别显示用户已提供的事实、系统建议和未知事项。编辑妆容方向不会替换已经开始的教学计划。
- FR-603 摄像头预览不上传。发送单张标签图前说明处理服务和用途，并单独确认。拒绝、供应商变化或配置不完整时不会调用远程服务。
- FR-604 标签显示原文及难辨字符。只有在清晰、原文支持的条件下显示色号、成分或使用文字。保留未读清的片段和不确定性。
- FR-605 产品比较并列有来源的属性，区分厂商资料、虚构示例和无来源资料。个人偏好独立显示，不从可见妆效推断适合性。
- FR-606 可用状态区分本地模拟、远程配置就绪与实际远程通过。缺少凭证时真实读取标为受阻。

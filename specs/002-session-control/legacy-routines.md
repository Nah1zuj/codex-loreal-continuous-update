# 旧教学流程接入统一命令

选择妆容方向时，旧目录流程只在当前会话中提供建议。首次明确开始时，服务端校验所选造型、目录流程与版本，把步骤标识、顺序、名称和进度写进同一个 SQLite 教学计划。计划创建、第一步与事件收据在同一事务提交。说明文字继续从对应版本的知识库读取。流程下架或版本变化后，继续教学需要重新选课。已提交事件仍可查询。

| 情况 | 权威状态和兼容输出 |
|---|---|
| 只选方向 | 尚无教学计划，预览可显示预计步骤数 |
| 已开始 | 计划中的版本、当前步骤和每一步状态；旧 `routine_started`、`routine_step` 和 `routine_total_steps` 由后端计算 |
| 暂停或恢复 | 保留计划位置，撤销媒体授权；恢复教学后需要重新授权媒体 |
| 跳过 | 该步骤保留跳过记录 |
| 结束教学 | 返回已确认步骤的小结，仍可继续会话；小结须另行确认才保存 |
| 结束会话 | 有教学计划时记录 `end_session` 事件，恢复后保持结束状态。未开始教学的空会话仍是临时会话 |

`/api/routine/start`、`/api/routine/advance`、文字和流式命令最终走同一事务。已提交结果可由本人通过事件查询接口读取。使用原事件 ID 重试时不会重复推进。旧客户端省略事件 ID 时仍可发命令，每次请求视作新事件。首次从目录开始前没有计划版本，之后可用计划 ID、版本和步骤拦截过期请求。

新增的目录引用、步骤引用和结束状态保存在既有计划载荷内。旧版可读的既有记录仍可读取。回退到旧代码前需要保留新库的备份并使用升级前的库副本，旧代码的计划验证器无法加载新格式的目录计划和已结束会话。旧版只在进程内保留过的进度无法跨进程恢复。

隔离回归覆盖旧启动接口、跨文本和 SSE 重放、事件查询、进程重启恢复、跳过与提前结束、目录下架及旧知识步骤显示。实体浏览器和语音验收见本阶段总记录。

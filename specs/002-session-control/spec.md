# TRACE 会话状态与控制

**编号** 002 · **阶段** 2 · **依据** [整改计划](../../docs/quality/roadmap.md)

## 用户场景

- **US-201** 在文字、按钮和语音中开始、推进、跳过、暂停、恢复或结束教学；同一动作使用同一业务规则。闲聊、否定、重复和解释时保留步骤。
- **US-202** 网络中断或连续点击后，可以从服务端查明操作结果；重试同一事件不会多执行一步。
- **US-203** 停止播报、丢弃录音、暂停课程和结束会话互相区分。刷新只恢复进度。
- **US-204** 结束后看见事实性小结，可继续交流或独立写日志。结束不会自动新增个人摘要。

## 要求与验收

- **FR-201** 教学计划由服务端掌握。进入已完成计划的小结时保留原计划；显式开启新的体验才能创建新计划。跳过标为跳过；提前结束保留真实状态。
- **FR-202** 命令带事件 ID、当前计划标识及必要的预期步骤和版本。相同事件重复提交只读回结果；事件与命令参数冲突或操作过期须拒绝。
- **FR-203** 兼容入口只负责翻译；快照中的旧进度字段从权威状态计算。文字、语音与旧按钮用同一业务服务。
- **FR-204** 请求中断后读取事件结果或当前状态。分开记录业务已提交、回复生成中、失败和完成。前端拒绝迟到响应。
- **FR-205** 暂停保留步骤；刷新和恢复不得恢复媒体授权。停止播报、清除录音、暂停课程及结束会话可分别执行。
- **FR-206** 关闭自动个人摘要写入及历史摘要的自动复用。旧资料保留来源、可由本人查看和清除。保留明确确认后的独立日志；阶段 7 实施完整版本确认和复用。

## 澄清

- 保留已有数据，原有自动摘要仅供查看和清除，不进入当前建议或问候。
- “还没完成”不可产生完成或推进。重复、解释与已完成后的再次结束不更改步骤版本。
- 暂停是教学控制命令，不等同于静音或结束。恢复以新授权周期开始。
- 本阶段软件工作可在 Windows 实体环境等待期间独立验证。工程交付仍依赖双平台验收。

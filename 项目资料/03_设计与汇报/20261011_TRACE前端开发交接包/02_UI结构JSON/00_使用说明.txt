TRACE UI JSON 使用说明｜2026-10-11

这是一份UI设计规格，不是可直接启动的网站，也不是后端API返回样例。
依据两份V2文档整理为7个页面：入口、语音陪伴、视觉探索、分步指导、相机检查、包装读取、偏好记忆。
同时包含按钮事件、共享状态、相机边界、无障碍降级和60–90秒视频走查顺序。

交给负责前端的同学：
1. 在实际React/Vite项目中核对现有路由、组件和会话状态。
2. 根据pages映射界面；event_contract是设计事件，需接现有处理函数，不能当作已经存在的API。
3. 将真实接口、Provider和颜色数值补齐；没有提供的信息保留null或NOT_TESTED。
4. 先跑通入口→语音/文字→指导→授权检查→返回，再制作视觉探索页面。
5. 录视频前走查acceptance_checklist；模拟数据标为MOCK，未审核内容标为DRAFT。

现阶段未提供源码或原UI截图，样式只整理了文档的语义色名与布局方向，没有声称还原具体画稿。
正式推荐依赖人工审核的Look/Routine；本文件不会把原候选知识升级为已审核。
保存JSON不会自动让Prompt或规则生效，需前端/Agent运行时接入。

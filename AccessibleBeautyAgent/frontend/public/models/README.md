# Optional owned human model

TRACE uses original procedural geometry by default. No third-party human model is bundled.

An owned or permissively licensed neutral head/bust may be placed at `human.glb`. Enable it with `<meta name="trace-human-model" content="/models/human.glb">` in `frontend/index.html`. Keep the model license with the asset. See `docs/TRACE_SENSORY_UI.md` for the normalization and generic-overlay limitations.

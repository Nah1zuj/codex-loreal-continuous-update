# TRACE Story local fonts

Prata-Regular.ttf: unmodified file from Google Fonts, Prata Project Authors.
Source: https://github.com/google/fonts/tree/main/ofl/prata
License: Prata-OFL.txt (SIL OFL 1.1).

NotoSerifSC-Story-0.ttf / -1.ttf: Google Fonts' text-subset responses for
Noto Serif SC 400 / 500, limited to fixed Story display characters. Remaining
characters use the declared local serif fallback; body text retains the app's
accessible sans serif. No user conversation was sent to request a subset.
Source: https://fonts.googleapis.com/css2 (Noto Serif SC family)
License: NotoSerifSC-OFL.txt (SIL OFL 1.1).

All font assets are served from this application. There is no browser-side
Google Fonts request, telemetry, or remote font dependency.

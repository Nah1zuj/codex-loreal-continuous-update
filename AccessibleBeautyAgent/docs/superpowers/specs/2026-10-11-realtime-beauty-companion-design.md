# TRACE 实时 Beauty Companion 设计规格

日期：2026-10-11  
状态：待用户最终审阅

## 目标

把现有 Voice / Visual 入口升级为同一个 Agent 驱动的连续通话体验。用户点击一次入口后即可像语音电话一样交流：自动聆听、发送、朗读回答并恢复聆听。视觉模式提供持续摄像头预览和有限、诚实的画面分析；旁栏呈现 Today's Look、当前建议、材料知识与经审核的参考内容。

产品面向残障群体，但入口不要求用户证明残障或披露健康状况。语音、视频和文字是平等的交互偏好，而不是身份分类。

## 体验结构

### 语音陪伴

用户从首页点击“语音陪伴”即进入通话面板，并利用这一次用户手势申请麦克风权限。授权后进入连续循环：聆听 → 识别完成 → 发送给现有 Agent → 自动朗读 → 朗读结束后恢复聆听。

主界面显示 AI 状态、实时字幕和最近回复。保留三个大按钮：暂停/继续聆听、切换文字、结束通话。摄像头默认关闭；用户明确开启后，以较小的镜面窗口提供本地预览和视觉辅助。

### 视觉体验

视觉体验使用同一通话循环和同一 `session_id`。连续摄像头预览是主画面，右侧编辑式旁栏显示当前造型状态、建议、材料和参考内容。用户仍可只说话，也可使用文字输入。关闭摄像头不会结束 Agent 会话。

### 模式切换

Voice 与 Visual 只是同一会话的两种呈现方式。切换时保留对话、步骤、Today's Look、当前确认项和待确认 Memory；停止媒体轨道时不重建 Agent。页面刷新只恢复服务器允许保存的会话状态，不自动恢复麦克风或摄像头权限。

## 通话状态模型

客户端媒体控制器使用明确状态：`idle`、`requesting_permission`、`listening`、`thinking`、`speaking`、`paused`、`ended`、`error`。

- 识别产生最终文本后停止本轮识别，进入 `thinking`，避免把 AI 语音重新识别成用户输入。
- Agent 回复完成后进入 `speaking`；TTS 结束才恢复 `listening`。
- 用户说“停止”、点击结束、切换到非通话页面或页面卸载时，中止识别、TTS、计时器和媒体轨道。
- 用户在 AI 朗读时主动开始说话，可点击“打断”立即取消 TTS 并恢复聆听；首版不依赖不稳定的自动语音打断检测。
- ASR、TTS 或网络失败均显示可操作错误并保留文字输入。

浏览器权限弹窗无法绕过。入口点击用于首次申请麦克风；摄像头仍通过独立、清楚标注的按钮开启。权限被拒绝时不重复骚扰用户。

## 视频和视觉分析

摄像头通过浏览器 `getUserMedia` 提供连续本地预览。画面不会作为整段视频上传。默认分析路径为本机；需要远程视觉模型时，界面说明将发送抽取帧、目标服务和用途，并要求当次明确同意。

分析调度器每 2–3 秒最多抽取一帧，且只有以下条件之一成立才进入分析：画面变化超过本地阈值、用户说“帮我看看”、当前妆容步骤要求一次检查。任何时刻最多一个分析请求；新请求不会排队堆积。远程分析关闭或拒绝时，保留本地预览和文字/语音流程。

视觉输出继续遵守现有边界：只描述当前任务可见状态；低光、遮挡、多人、偏头或不确定结果返回 `UNCERTAIN`、重拍或跳过。照片或视频外观不能确定衣物纤维、残障、健康状态、真实情绪或气味。左右以用户身体左右为准，未经验证不得宣称精确度。

首个可交付版本接入现有 ECHO/vision gate，并实现浏览器视频预览、抽帧调度与模拟/本地契约。真实远程视觉仍受现有配置和每次授权控制。

## 组件边界

- `RealtimeCallController`：管理 ASR、TTS、状态转换、打断与自动恢复聆听。
- `CameraStreamController`：管理权限、`MediaStream` 生命周期、前后摄像头选择和轨道释放。
- `FrameAnalysisScheduler`：控制帧率、变化检测、单飞请求、授权和结果过期。
- `VoiceCallView`：语音优先的大字幕、呼吸粒子和极简控制。
- `VideoCallView`：视频镜面主舞台与编辑式建议旁栏。
- 现有 `AgentHarness`、会话、Full Look、Memory 和 consent 状态机保持唯一业务来源。

媒体对象、音频、视频帧和识别中间结果只保存在内存中，不进入 sessionStorage、Memory 或日志。仅最终用户文本和现有会话结果按当前规则处理。

## 视觉语言

界面不是美妆电商，也不是传统 AI 仪表盘。设计语言为 soft luxury 数字 Beauty Companion：高端香氛官网、艺术展览网页和未来 Beauty AI 的结合。

色彩使用暖象牙白、香槟杏桃、烟粉、深可可和克制的金属铜。大面积留白承载雾感光晕与柔和 3D 形体。电子粒子数量低、速度慢，并只在聆听、思考、朗读状态产生微弱响应。视频窗口像悬浮镜面或艺术装置，不使用常规黑色视频会议框。

旁栏采用编辑册式排版：大标题、小型编号、细线、材料与建议的图文节奏。避免重复卡片、粗重阴影、霓虹赛博风、密集按钮和电商商品瀑布流。图像只使用权利明确并通过审核的素材；没有合规素材时使用抽象生成视觉或纯排版。

页面切换使用透明度、轻微位移和雾光过渡。滚动触发只用于内容进入，不阻碍阅读。`prefers-reduced-motion` 下关闭粒子位移、3D 跟随、滚动变换和连续视差，只保留即时状态变化。所有文字维持可读对比度，控件支持键盘、读屏名称和大触控区域。

## 语言与本地化

中文和英文是两个干净、完整的界面版本。语言按钮切换当前语言，而不是同时显示两种语言或只改变排列顺序。无障碍名称、状态提示、错误、权限说明、通话字幕和 Today's Look 都必须使用当前语言；产品名或无法合理翻译的专名可保留原文。

陪伴语言应有安静的哲思和文学感，关注选择、身体经验、时间、自然与自我呈现，但不模仿或拼贴任何作家的具体句式。每次回复先给清楚、可执行的信息，再用最多一句短而自然的哲思表达提供陪伴感。避免玄虚、说教、怜悯、幼儿化、诊断、假装理解用户内心，以及让文学修辞覆盖安全步骤。

语言升级优先通过版本化 Policy、经审核的示例、RAG 和回归评估完成。没有足够的授权对话语料、人工评分规范和独立测试集前，不进行模型微调或宣称“语言训练完成”。

## 错误与安全回退

- 麦克风拒绝：显示原因、浏览器设置提示和立即可用的文字输入。
- 摄像头拒绝：通话继续，旁栏保留；不自动再次弹窗。
- ASR 不支持：文字输入继续，TTS 可独立使用。
- TTS 不可用：回复以大字幕显示，自动聆听需由用户再次启动，避免状态不明。
- 网络/模型失败：使用现有本地策划流程和明确的候选状态；不伪造实时视觉结果。
- 页面隐藏或离开通话页：停止摄像头与持续识别，返回后由用户重新开始媒体。

## 验收标准

1. 首页一次点击 Voice 后出现浏览器麦克风权限；允许后无需第二次点击即可聆听。
2. 用户说完后自动发送，AI 自动朗读，朗读结束自动恢复聆听，不发生自我回声循环。
3. 暂停、打断、结束和文字回退可用；结束后没有活跃媒体轨道或计时器。
4. Visual 显示连续本地视频和旁栏；切换 Voice/Visual 保留同一会话与计划。
5. 摄像头和远程抽帧分别获得明确同意；拒绝任一项不阻塞语音/文字。
6. 抽帧间隔不短于配置值，单飞请求，不上传整段视频，不持久化帧。
7. 视觉不确定时不编造结论；材料成分只能来自标签、官方信息或用户明确确认。
8. 桌面和窄屏布局可用；键盘、可读名称、减少动态和高对比文本通过自动与人工检查。
9. 现有 Full Look、THREAD、DOT、PAIR、ECHO、IMPRINT、Admin 和 API 回归通过。

## 测试策略

单元测试覆盖通话状态机、TTS 结束后恢复、打断、权限拒绝、媒体轨道释放、帧调度节流、单飞请求和过期响应。React 测试覆盖入口一次启动、文字回退、模式切换和旁栏状态。浏览器测试覆盖真实权限提示之前的用户手势链、模拟媒体流、页面离开清理、桌面/窄屏、控制台健康和减少动态。真实麦克风、TTS、摄像头和远程视觉分别记录 `TESTED` 或 `NOT_TESTED`，不以 Mock 冒充硬件结果。

## 非本轮目标

不训练自有视觉模型，不宣称连续视频的医学、美学或准确率能力，不自动保存录像，不进行多人视频通话，不迁移为原生移动端或微信小程序，不发布版权不明的参考图片。

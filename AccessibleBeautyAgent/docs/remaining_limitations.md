# V2 剩余限制

功能修补已覆盖真实流式对话、六项受控工具、多轮上下文、逐句 TTS、手动打断、文字回退、新帧本地原型、受使用权约束的知识导入、匿名浏览器隔离、确认日志/原文及日历。

以下未完成，不能称整份 Master Prompt 的全部生产目标已实现：

- 精确 landmarks、真实妆效识别、校准置信度、视觉金标准评估或训练。当前 OpenCV 矩形区域代理永远 UNCERTAIN，无真人远程帧测试。
- 自建流式 STT/TTS、服务端 VAD、真实全双工自动打断、麦克风/扬声器/相机/读屏设备验收。浏览器识别可能依赖供应商远程处理。
- 生产账户登录、跨设备同步、匿名身份恢复、旧 demo 数据授权迁移、后台定期过期删除、备份级删除。
- 专家审核大规模教程、许可爬虫、完整 L’Oréal SKU/库存/价格/购买链接；现有集合仍小且多数 demo，新段为原创待审核草稿。
- 自动上下文摘要、完整每一步持久事件审计、端到端费用计价、其他兼容供应商实际调用、长时并发/公网限流与部署。

下一步 UI 按用户新 Story 说明独立迭代，先审计 `/story`，不重新实现/破坏这里已经验收的对话、相机、日志和知识逻辑。新粒子艺术不叫模型训练或视觉准确率提升。

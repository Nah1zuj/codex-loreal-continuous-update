# Vision evaluation and annotation protocol

Inference version: `trace-local-lab-v1`. No foundation-model training or fine-tuning was performed. Official pretrained [MediaPipe Face Landmarker](https://developers.google.com/edge/mediapipe/solutions/vision/face_landmarker/python) localizes points; [OpenCV color conversion](https://docs.opencv.org/4.x/de/d25/imgproc_color_conversions.html) supplies floating-point LAB. Detected geometry is not a makeup accuracy score.

`MAKEUP_EVALUATION_SCHEMA.json` describes local asset references, consent and separate evaluation/calibration/training rights, lighting/pose, face/cheek/lip localization boxes, human appearance labels, predictions, version and before/after pair labels. Asset references are not fetched by scripts. Runtime frames are not an implicit dataset. Withdrawal excludes a record; evaluation permission does not grant training permission.

Annotators should label unmirrored pixels using the subject's anatomical sides, record face/region boxes as x,y,width,height, separate observable color prominence from attribution to blush, and mark occlusion/poor light/uncomparable views rather than guessing. Use two reviewers and adjudicate disagreements; document skin-tone/light/camera strata. Before/after samples require independent comparability and change labels. Consent documents and images live in a separately controlled store, never public repository fixtures.

Install the optional offline dependency with `python -m pip install -r backend/requirements-evaluation.txt`. Then run `python scripts/evaluate_makeup_vision.py authorized.jsonl --output report.json`. Only authorized `real_labeled` samples with human labels and predictions produce metrics. Empty/synthetic/unlabeled input reports NOT_EVALUATED. Metrics include per-class false positives/negatives, agreement, localization IoU, poor-light error, stable-pair consistency and change-direction agreement, with denominators and unavailable values explicitly null.

Run `python scripts/calibrate_makeup_thresholds.py authorized.jsonl` to recommend (not activate) a LAB difference threshold using at least 30 explicitly calibration-authorized real samples. Calibration-set agreement is not held-out accuracy. Validate on an independent holdout and report strata before changing production thresholds. No training routine is coupled to production inference.

Engineering quality defaults: frontal face area 0.08–0.85 of frame; grayscale brightness 45–220; Laplacian variance >=20; cheek L difference <=12 (float LAB L=0–100); normalized nose offset <=0.22; roll <=20 degrees. Cheek color difference default |a-left minus a-right|<=3 is an appearance heuristic. Recheck accepts average L change<=8, face-area change<=0.04, nose-offset change<=0.08 and bounds shift<0.06. Head yaw is a dimensionless 2D proxy, not calibrated yaw/pitch degrees. Strong highlights/dark patch pixels are excluded; inadequate patch area is rejected. Absolute blush/product coverage, attribution to cosmetics and validated occlusion detection are not available.

Next improvement order: authorized data and error analysis → preprocessing → landmark/ROI geometry → threshold calibration → pretrained segmentation comparison → small specialized model only if evidence requires it. No real labeled dataset was supplied in this task. Synthetic unit fixtures test arithmetic and integration only, not clinical or makeup accuracy.

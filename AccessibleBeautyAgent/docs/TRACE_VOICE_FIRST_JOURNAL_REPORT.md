# TRACE 语音优先、真实文本辅导与私人日历验收

日期：2026-10-12。分支：trace-v5-realtime。原 Task 1–7 已按顺序提交；本文记录之后用户明确要求的扩展。

## 本轮实现

- 顶部入口缩为首页、语音通话、图文陪伴、我的记录。旧模块作为辅助功能保留。纯语音不显示推荐旁栏，图文模式保留已有造型和来源资料。
- 首页尝试朗读欢迎、聚焦语音入口，提供手动重播及文字入口。页面加载不采集麦克风；浏览器阻止自动播放时需点击。
- 真实 DeepSeek 文本辅导解释当前步骤；自然开始/下一步指令进入或推进确定的流程。短回答附带上次回复作为有限上下文。模型不能自行推进或确认保存。
- 步骤按钮通过通话控制器发送、朗读；暂停状态不自动打开麦克风。回答优先展示，固定步骤折叠为参考。
- 苹果标识、暖光粒子、粒子苹果、鼠标跟随和 GSAP 容器动画。提供关闭动效；reduced-motion 静态；离页清理事件和动画。React Bits 为灵感参考，没有引入其组件代码；没有调用不可用的 Product Design 工具。
- 私人文字日历：妆容主题、感受、反思和本人确认的特质；确认后保存、查看、删除。特质摘要只汇总本人保存的描述。分享仅生成可编辑、可复制的草稿，没有公共发布。
- 可复现文本启动器 scripts/run_realtime_text.py：正常加载被授权的已有配置；所有图像服务保持 Mock；仅监听 loopback。

## 仍需处理的产品风险

本地单用户原型使用 demo/user_id，owner 过滤不是登录认证；SQLite 记录不等于加密或公网隐私保证。公开部署前必须实现身份认证、访问控制、删除/备份策略和隐私设计。

现有教程仍是少量示例，尚未成为完整专家审阅妆教库。已阅读 [RNIB 无障碍化妆建议](https://www.rnib.org.uk/living-with-sight-loss/independent-living/applying-make-up/)，仅保存自行归纳的候选笔记，未批量复制网页。公开网页不自动具备开源再分发许可。

通用 API 已有语言能力，接入无需先训练；当前优先提示词、合法检索上下文、流程约束和独立评测。见 [OpenAI 模型优化说明](https://developers.openai.com/api/docs/guides/model-optimization)。模型仍可能回答不准确；提示词和结构校验不等于正确性保证。更长的朋友式长期对话和自动日志摘要尚需独立设计与评测；当前不是完整无限上下文聊天。

真人视觉需要当次服务/目的同意、授权样本、人物隔离的独立测试集及误报/漏报/不确定性评估。没有这些证据不能宣称“看脸准确”或“训练完成”。原海报的公开使用许可尚未确认，当前按用户提供素材本地展示。

没有查看、输出或修改配置文件内容/API Key。依据用户当次明确允许，由运行中的应用正常加载原项目已有配置，仅向 DeepSeek 发送文本；没有上传/保存整段录像。

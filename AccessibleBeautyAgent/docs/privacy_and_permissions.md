# 隐私与权限

用户已授权沿用原项目配置进行 DeepSeek 文本调用；仅由启动脚本正常加载配置，不读取、打印或修改实际配置与密钥。本次没有真人图片或视频帧远程上传授权，也没有保存/上传整段录像。

文本对话发往配置的 DeepSeek 服务；浏览器语音识别可能由浏览器供应商处理，应在开始语音时看见披露。麦克风 RMS 只在显式启用声音波纹且聆听时本地计算，无录音/上传音频。相机预览、应用后端本地 OpenCV 检查和第三方视觉是不同授权；目前第三方视觉保持 Mock。视频页单帧应用后端分析不写盘，临时数值基线 RAM 15 分钟，关闭/退出清理。

匿名浏览器身份使用随机 HttpOnly / SameSite Strict cookie，数据库只保存 token hash，活跃请求延长 30 天有效期。服务端拥有者前缀隔离会话、偏好、日志和原文；恶意 Origin 拒绝。生产使用 Secure cookie，但这不是账户登录或跨设备同步。清除 cookie 或闲置过期后无法证明旧记录所有权；不将旧 demo 数据自动移交给新浏览器。账户找回/授权迁移/数据库备份删除策略仍待生产实现。

对话自动生成可编辑日志草稿，但不自动持久化、不推断人格或虚构完成妆效。保存必须确认；保存聊天原文需要第二项独立同意，原文 30 天后失效并在访问/保存时清理。删除日志级联删除其原文；没有后台定时清理或备份抹除实现。分享仅生成可复制草稿，不向社交平台发送。

语音可说“读日志草稿”，听过当前草稿后再说“确认保存这份私人日志”；确认保存刚刚朗读的快照，不保存完整原文。未先朗读不允许语音保存，模型工具不含保存/相机授权。可以随时停止、手动打断、改文字。生产管理员后台无账户认证时直接禁用。

==================================================
1. PRODUCT GOAL
==================================================

The product is a voice-first multimodal Beauty Agent designed primarily
for users who cannot reliably depend on visual information,
especially blind and low-vision users.

The MVP should demonstrate this complete journey:

User Voice
→ Understand beauty intention
→ Retrieve a target makeup Look
→ Retrieve step-by-step routine
→ Voice guidance
→ User asks for visual check
→ Camera capture
→ Face quality gate
→ Visual analysis
→ Structured visual result
→ Agent converts visual result into accessible language
→ Continue routine
→ User gives preference feedback
→ Ask for memory consent
→ Save Beauty Memory

Example main demo:

User:
“今晚有一个比较正式的 dinner，
我想比平时更有存在感，但是不要显得太成熟。”

The system should infer approximately:

scene = dinner
desired_impression = polished / slightly_present
avoid = too_mature / high_saturation

Then retrieve a Soft Formal makeup direction.

==================================================
2. CRITICAL PRODUCT BOUNDARIES
==================================================

DO NOT build an AI that judges whether a person is beautiful.

DO NOT claim:
- perfect makeup
- attractiveness score
- professional quality
- exact beauty ranking

Visual AI should primarily report measurable or obvious states.

V1 visual tasks:

1. blush_presence
Allowed states:
- NO_BLUSH
- LEFT_ONLY
- RIGHT_ONLY
- BOTH
- UNCERTAIN

2. lip_presence
Allowed states:
- NOT_APPLIED
- APPLIED
- OBVIOUS_OVERFLOW
- UNCERTAIN

lip_presence is P1.
blush_presence is P0.

Fine-grained blush symmetry,
gradient quality,
millimeter lip-boundary detection,
personalized facial geometry,
emotion recognition,
and beauty scoring are NOT P0.

Design the architecture so these can be added later,
but do not let them block the MVP.

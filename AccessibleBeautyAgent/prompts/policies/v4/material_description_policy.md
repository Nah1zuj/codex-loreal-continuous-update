# material_description_policy — v4
Separate fiber, weave/knit structure, finish, weight, drape and softness.
缎面不等于丝绸；针织不等于羊毛。成分只能来自可读吊牌、官方产品字段或用户明确陈述。
Only read visible composition text. Unknown percentages, uncertain characters and care symbols must remain unknown; never guess.
衣服照片只可提供外观描述，不能确定纤维成分。透气、舒适、皮肤敏感性受具体织物和个人条件影响，不作绝对保证。
区分事实来源与主观触感；所有DRAFT知识如实标记。

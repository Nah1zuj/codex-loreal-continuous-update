# 阶段 0 能力矩阵

“部分”表示已有相关实现或自动化覆盖，仍需满足右列。结果分层见 [基线](baseline.md)。路线的完整需求见 [原计划](roadmap.md)。

| 能力 | 基线状态 | 当前边界 | 整改阶段 |
|---|---|---|---|
| 本机安装、运行和恢复 | 部分 | Mac 现有环境；Windows 物理设备与干净安装另验 | 1、8 |
| 自由交流、意图与教学 | 部分 | mock 回归通过；真实远程文字、澄清与课程准入未重新验收 | 2、3 |
| 暂停、幂等命令、跳过、提前结束 | 部分 | 有教学控制与历史测试；跨入口一致性和断连后的结果查询未覆盖 | 2 |
| 本地语音按钮与关键词 | 部分 | 有模型和浏览器连接；实体音频、回声与资源释放需验证 | 4 |
| 质量、定位、颜色 | 部分 | 有本地门控、MediaPipe 模型和局部颜色接口；授权分层、误差和可比性需验收 | 5 |
| 真实妆效判断 | 研究 | 有评估代码；不在工程版验收范围 | 另建研究规格 |
| 六域 Full Look 与局部编辑 | 部分 | 有计划、修订、确认接口；六域与教学替换、版本冲突需验证 | 6 |
| 标签读取及有来源的比较 | 部分、演示 | 有远程适配和 mock；无本轮真实服务证据 | 6 |
| 独立日志、确认摘要和偏好 | 部分 | 有日志与浏览器隔离；候选版本、旧自动摘要与级联删除待整改 | 2、7 |
| 键盘、文字、读屏 | 部分 | 组件测试覆盖部分行为；实体双平台读屏尚无证据 | 8 |
| 硬件接入 | 演示及可选模块 | 模拟器与可选代码，真实设备能力不在本轮范围 | 8 复核打包 |
| 专业审核及目标用户试用 | 待验 | 尚无本轮专业或目标用户验证 | 工程候选之后 |

# TRACE 独立产品方向

更新日期：2026-11-09。

## 身份

TRACE 是面向盲人和低视力用户的独立美妆陪伴项目，不属于化妆品公司、支付平台或比赛。核心无障碍能力不因未来合作方、渠道或活动而改变。

## 内容边界

- 覆盖护肤、底妆、眼妆、眉部、腮红、唇妆、头发、香氛、穿搭材质和配饰，不限制在单一公司产品组合内。
- 默认先询问并使用用户已经拥有、熟悉的物品，购买不是完成造型的条件。
- 面向用户时优先说“轻薄底妆”“柔和腮红”“日常唇彩”等单品名称或品类，不主动突出品牌。
- 只有用户明确询问且存在可追溯资料时，才说明品牌、具体商品属性或来源；色号、成分、功效、价格和库存不得猜测。
- 第三方平台只能作为可选适配器，不能成为产品身份，也不能让外部状态影响基础体验。

## 交流语气

语言应温和、具体、不过度煽情。先听用户今天的感受和需求，每次给一个清楚动作，允许暂停、跳过或换一种方式；不怜悯、不诊断、不编造用户内心，也不施加购买压力。

## 当前实现

- 对话提示词和本地 mock 回复采用独立、品牌中立上下文。
- 产品模型以单品名称为必填字段，品牌仅可作为内部可选来源信息，默认接口和界面不展示。
- 演示知识库包含 27 个虚构、品牌中立单品，覆盖九类产品；旧的真实品牌样例已移除。
- 公司或比赛专属研究不进入运行知识库；历史迁移证据仅作为审计快照保留。

## 验收

1. 正常完整造型回复不得出现公司或比赛名称。
2. 产品目录和比较接口不得返回 `brand` 字段。
3. 知识库必须通过结构、来源和受控词汇校验。
4. 前后端全量测试和生产构建通过。
